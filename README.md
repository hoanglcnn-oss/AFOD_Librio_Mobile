# AFOD Librio Mobile Workspace

Workspace quản lý mã nguồn, tài liệu và tiến trình phát triển ứng dụng di động **Librio** (AFOD).

---

## Cấu trúc Workspace

```text
AFOD_Librio_Mobile/
├── week34_project/       # Project Flutter chính của ứng dụng Librio
├── DLC_Flutter/          # Tài liệu đặc tả, hướng dẫn và requirements ban đầu
└── Flutter_Tracking/     # Ghi chép, tài liệu và file theo dõi quá trình học tập Flutter
```

---

## Chi tiết các thư mục

### 1. `week34_project/` (Project chính)
- Mã nguồn ứng dụng di động Flutter chính thức của **Librio Mobile Application**.
- Áp dụng kiến trúc Clean Architecture + BLoC, hỗ trợ đa nền tảng và đã được thiết lập đầy đủ test suite.
- Chi tiết về cách chạy ứng dụng, cấu hình biến môi trường (`API_BASE_URL`), cấu trúc module nghiệp vụ và quy ước lập trình xem tại [week34_project/README.md](file:///d:/lifetime/AFOD_Librio_Mobile/week34_project/README.md).

### 2. `DLC_Flutter/` (Docs ban đầu)
- Chứa các tài liệu đặc tả nghiệp vụ, wireframe/UI flow, API contracts và checklist màn hình ban đầu của dự án.

### 3. `Flutter_Tracking/` (Tracking & Học tập)
- Chứa các file ghi chép, nhật ký theo dõi quá trình học tập, thử nghiệm và thực hành Flutter trong suốt giai đoạn phát triển.
